# Dijkstra - Sistema de Gerenciamento de Restaurantes

<p align="center">
  <img src="docs/assets/logo.png" alt="Logo Dijkstra" width="420">
</p>

O **Dijkstra** é um sistema web desenvolvido para auxiliar restaurantes no gerenciamento de mesas, pedidos, produtos e usuários, proporcionando uma plataforma moderna, intuitiva e eficiente para otimizar o atendimento e a administração do estabelecimento.

A aplicação permite que funcionários registrem pedidos, acompanhem o status das mesas e gerenciem produtos, enquanto administradores possuem ferramentas para controlar usuários, cardápio e operações do restaurante.

## 1. Clonar o Repositório

```bash
git clone https://github.com/FGA0138-MDS-Ajax/2026.1-T03-Dijkstra.git

cd 2026.1-T03-Dijkstra
```

---

## 2. Configurar o Backend

```bash
cd backend

python -m venv venv

# Windows
venv\Scripts\activate

# Linux
source venv/bin/activate

pip install -r requirements.txt

python app.py
```

---

## 3. Configurar o Frontend

```bash
cd frontend

npm install

npm run dev
```

---

## 4. Configurar o Banco de Dados

Crie um banco PostgreSQL e configure o arquivo `.env`.

Exemplo:

```env
DATABASE_URL=postgresql://usuario:senha@localhost:5432/dijkstra

SECRET_KEY=sua_chave

PORT=5000
```
